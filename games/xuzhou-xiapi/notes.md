# 下邳之战 · WPE 游戏包手册

《徐州之战》的衍生剧本（表驱动，复用其地图与算子，无引擎逻辑改动）。
建安三年(198)冬，曹操东征徐州，与刘备合围吕布于下邳。

## 剧本：曹操刘备讨吕布 · 下邳之围（scenario.json）

- **背景**：吕布袭取徐州后据下邳，曹操亲率大军东征，刘备自小沛来会。联军围下邳数月，
  引沂、泗之水灌城，吕布部将叛降，城破被擒。
- **对阵（2 人联军）**：owner 0 = 曹操(blue)+刘备(red)，共 **22** 枚；owner 1 = 吕布(yellow)，**14** 枚。
- **部署**：
  - 曹操 14 枚自西压上（彭城以西，约 3–8 列 / 8–10 行）；刘备 8 枚自北小沛 `(5,3)` 南下；
  - 吕布亲率主力于 **下邳**(18,12) 及周边**营垒**列阵（9 枚），张辽领 5 枚守 **彭城**(9,8) 为犄角。
- **胜利**：
  - 联军：攻占下邳（`objectivesHeld(0) >= 1`），或累计歼敌战力 ≥ 18（`destroyedStrength(0)`），或全歼敌军；
  - 吕布：坚守至第 12 回合仍保有下邳（春至曹粮尽退兵），或全歼敌军。

## 平衡设计（本剧本的重点）

初版联军 22 枚对吕布 9 枚，攻方碾压。现保留联军全员（22 枚），把平衡重心放在**守方兵力与城防**，形成"围城-断粮-强攻"的博弈：

1. **守方增强**：吕布 9 → 14（新增 陷阵营B、并州铁骑B、吕布·部曲D/E/F），并适当下调吕布与陷阵营战力（7/5 → 6/4），
   使坚城可被高骰击退而非绝对不可破。
2. **城防地形**：在下邳周围铺一圈 **营垒（T 城镇地形，防御 +1）**，形成要塞群与 ZOC 卡口；
   攻方先啃外围营垒再临城，机动被地形与 ZOC 迟滞。
3. **战斗列移位（`combat/oddsShift`）**：CRT 增加列修正
   `-terrainDefense(target)`（守方地形/城防）与 `if(inSupply(target),0,1)`（守方断粮则易攻）。
   于是**围城断粮**成为破城关键：切断下邳至东侧补给源的粮道后，守军失去城防列加成，强攻方可奏效。

> 数据核实（无头自动对局，12 个随机种子，贪心 AI）：守方（吕布）约 11/12 取胜，攻方 1/12 靠战损取胜。
> 贪心 AI 不会绕后断粮，人类攻方通过机动切断东侧补给线、集中强攻下邳，胜率会显著提高——这正是本剧本的玩法核心。

## 新规则（相对《徐州之战》新启用的能力）

`game.json` 在 `family: default` 上逐项覆盖，全部为组合既有变体：

| 能力 | 变体 | 玩法作用 |
|---|---|---|
| `zoc` | `zoc` | 控制区：进入敌 ZOC 必停、离开加费（河流不投影） |
| `movement` | `zoc` | 行动点移动 + ZOC 约束 |
| `combat` | `oddsShift` | 战力比 + **列移位**（城防/地形、守方断粮），较 `crTable` 更适合表达城防 |
| `territory` | `controlPoints` | 每格归属；部署时按下位初始化 |
| `supply` | `traceLine` | 补给线追溯；**断粮**：移动力 -1，且攻击受城防修正惩罚；双方补给源分别在西侧/北侧与东侧边缘 |
| `stacking` | `perHex` | 每格堆叠上限 3 |
| `victory` | `objectives` + `attrition` | 目标点与战损两套胜利规则叠加 |

> 结果结算用内核 `eliminate` 标记歼灭，供 `victory/attrition` 的 `destroyedStrength` 统计。

## 地图与地点标注（map.json）

复用《徐州之战》24×15 地图；`map.json` 的 `labels` 字段标注重要地点，渲染器
（`wpe overlay` 与图形界面）在格上用文字标出：

- 城镇：下邳(18,12)★、彭城(9,8)、郯城(17,4)、小沛(5,3)、广戚(8,5)、萧县(4,10)
- 军事：营垒（下邳要塞群）
- 水系：泗水、沂水、汴水
- 地貌：泰山、丘陵

★ = 目标点（`victoryHexes`，仅下邳）。

`labels` 为新增地图数据字段（`GridMap.Labels`），仅展示、不影响规则；绘于算子之上、格顶，
故地名与驻军名可同时看清。

## 数据表

- `game.json`：主规则（见上），行动含 move/attack/recover/pass/endphase，并给 `play` 增加可选 `--turns N`
- `units.json`：复用徐州算子并新增 5 枚吕布部队
- `combat.json`：`oddsShift` 表（在原 CRT 基础上扩展列值以吸收移位）
- `movement.json`：地形费/防御（T/F/H +1）
- `scenario.json`：本剧本部署

## 运行

```
wpe verify   games/xuzhou-xiapi      # 校验（应通过）
wpe play     games/xuzhou-xiapi      # 无头对局（默认 12 回合；--turns 15 可加长）
wpe overlay  games/xuzhou-xiapi      # 渲染地图 PNG（含地点标注）
wpe counters games/xuzhou-xiapi      # 批量出白板算子（art/）
Wpe.App      games/xuzhou-xiapi      # 图形界面（双人热座）
```
